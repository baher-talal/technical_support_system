# نظام إدارة الدعم الفني (Help Desk) — Laravel 12 / PHP 8.2 / MySQL

## التشغيل
```
composer install
php artisan migrate
php artisan db:seed        # أول مرة فقط
php artisan serve
```
اضبط قاعدة البيانات في `.env`.

## سير العمل
موظف ينشئ تيكيت ← مدير عام النظم والمعلومات يقبل (ويحدد التكنيكال) أو يرفض ← التكنيكال يبدأ ويصرف المستلزمات ويغلق ← صاحب الطلب يقيّم الحل أو يعيد فتحه.
كل خطوة تُسجَّل في سجل المتابعة، وتصل إشعارات مرئية وصوتية (كل 15 ثانية).

## المميزات
- تيكيتات: محادثة وتعليقات، إعادة إسناد، إعادة فتح، تقييم الحل، مشاركة واتساب، حذف (بصلاحية).
- موعد مستهدف للحل حسب الأولوية (`sla_hours` في `config/helpdesk.php`) مع وسم «متأخر».
- لوحة تحكم بمؤشرات ورسوم بيانية، وتقارير بنسبة الالتزام بالموعد وأداء التكنيكال، وتصدير التيكيتات والأجهزة إلى Excel.
- أجهزة الشركة وComputer ERP System (جدول مدمج أو بطاقات + استيراد/تصدير Excel) والإدارات (مبنى/دور/غرفة).
- القطاعات: رئيس قطاع مسؤول عن عدة إدارات يرى تيكيتاتها ويصله إشعار بالجديد منها.
- ملصقات QR للأجهزة: مسح الملصق يفتح تيكيتا جديدا بالجهاز محددا (طباعة من صفحة أجهزة الشركة).
- سجل النشاط (من فعل ماذا ومتى) ونسخ احتياطي تلقائي يومي لقاعدة البيانات.
- أدوار وصلاحيات قابلة للتعديل، وصلاحيات مخصصة لكل مستخدم.
- صفحة «حسابي» لتغيير كلمة المرور ورقم الهاتف، والوضع الداكن.

## ملاحظات
- حذف مستخدم = تعطيل للحفاظ على سجل التيكيتات، ويُخرَج المعطّل من جلسته فورا.
- مفتاح الدولة لأرقام واتساب: `country_code` في `config/helpdesk.php`.

## النسخ الاحتياطي والمجدول
- النسخة اليدوية: من شاشة «النسخ الاحتياطي»، أو `php artisan backup:db`. تُحفظ في `storage/app/private/backups` (آخر 14 نسخة).
- الأوتوماتيكي (يوميا 2:00 صباحا) يحتاج تشغيل المجدول كل دقيقة. على Windows: Task Scheduler ← مهمة كل دقيقة تشغّل `php artisan schedule:run` من مجلد المشروع. وللتجربة: `php artisan schedule:work`.
- الاستعادة: استورد ملف `.sql` (أو `.sql.gz`) في phpMyAdmin، أو `gunzip < backup.sql.gz | mysql -u USER -p DBNAME`.
- سجل النشاط يُحذف منه ما تجاوز سنة تلقائيا (أسبوعيا عبر نفس المجدول).

## الصلاحيات الجديدة
`audit.view` و`backup.manage` لمدير النظام فقط، ويمكن منحها لأي دور أو مستخدم.

## سجل صيانة الجهاز
افتح أي جهاز شركة (نافذة الجهاز ← «سجل صيانة الجهاز») لترى كل تيكيتاته، وعدد الأعطال والمستلزمات، ومتوسط زمن الحل، ورسم الأعطال لآخر 12 شهرا. يُوسَم الجهاز «كثير الأعطال» عند وصول تيكيتات العطل إلى `device_alert.repairs` خلال `device_alert.days` يوما (في `config/helpdesk.php`). ويمكن ترتيب قائمة الأجهزة بالأكثر أعطالا أو عرض الموسومة فقط.

## ملصقات QR
اضبط `HELPDESK_PUBLIC_URL` في `.env` على العنوان الذي يستخدمه الموظفون (مثل `http://192.168.1.10`)، وإلا يُكتب في الرمز عنوان الصفحة التي طُبع منها الملصق. مكتبة الـ QR مضمّنة (`public/vendor/qr`) ولا تحتاج إنترنت.

## العمل بدون إنترنت
شغّل مرة واحدة على جهاز عليه إنترنت ثم انشر مجلد `public/vendor`:
```
php artisan assets:install
```
قبل وجود الملفات تعمل الصفحات عبر CDN كاحتياط.

## هيكل كود التيكيتات
`TicketController` (HTTP فقط) ← `app/Http/Requests/*` (التحقق والصلاحية) ← `app/Policies/TicketPolicy` ← `app/Services/TicketWorkflow` (تغيير الحالة والسجل والإشعارات).
